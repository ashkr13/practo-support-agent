1) Real crew responses, validated in code with CrewResponse.model_validate_json():
   VALID   'How long will my thyroid test results take?' -> intents=['policy'] grounded=True
   VALID   'What is the status of APT-1038?' -> intents=['appointment_lookup'] grounded=True
   VALID   'What is the capital of France?' -> intents=['policy'] grounded=False

2) Malformed outputs are rejected before reaching a patient:
   REJECTED missing answer       -> Crew output failed schema validation: 1 error(s)
   REJECTED unknown intent       -> Crew output failed schema validation: 1 error(s)
   REJECTED score out of range   -> Crew output failed schema validation: 1 error(s)
   REJECTED not JSON at all      -> Crew output failed schema validation: 1 error(s)
